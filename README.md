# StaySaga - Hệ thống quản lý và đặt phòng homestay

## Giới thiệu

StaySaga là hệ thống web full-stack hỗ trợ quản lý và đặt phòng homestay. Hệ thống gồm 3 nhóm người dùng chính:

- Guest/User: tìm kiếm chỗ nghỉ, đặt phòng, xem chuyến đi.
- Host/Partner: đăng và quản lý chỗ nghỉ, phòng, giá, ảnh, booking.
- Admin: quản lý người dùng, chỗ nghỉ, đặt phòng, đánh giá và thống kê.

## Công nghệ sử dụng

- Next.js App Router
- TypeScript
- Tailwind CSS
- Supabase Auth
- Supabase Database
- Supabase Storage
- Supabase Realtime
- Supabase Row Level Security
- Dockerfile
- Docker Compose
- Azure VPS
- Caddy reverse proxy
- HTTPS domain: https://staysaga.duckdns.org
